# Employee Sentiment Analysis

## Overview
This project analyzes employee message data to determine sentiment trends,
employee engagement, and potential flight risks.

## Tasks Implemented

✔ Sentiment labeling (Positive / Neutral / Negative)  
✔ Exploratory Data Analysis  
✔ Monthly sentiment score calculation  
✔ Employee ranking  
✔ Flight risk detection  
✔ Linear regression sentiment modeling  

## Setup

Install dependencies

pip install -r requirements.txt

Run notebook

jupyter notebook notebooks/employee_sentiment_analysis.ipynb
